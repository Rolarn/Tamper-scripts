# Inoreader: фото прямо в ленте и быстрая навигация

**[⬇ Установить](https://raw.githubusercontent.com/Rolarn/Tamper-scripts/main/scripts/inoreader-photo-inline/inoreader-photo-inline.user.js)** · [История изменений](CHANGELOG.md)

Для лент, где в RSS приходит только заголовок, а фото есть лишь на странице поста (например, Tumblr-блоги с пометкой 18+). Скрипт достаёт фото сам и показывает его прямо в Inoreader — без перехода на сайт.

## Что делает

- Справа внизу две круглые кнопки, они есть во всём Inoreader:
  - **синяя ↓** (в фото-папках) — сохранить фото в максимальном доступном размере и открыть следующую запись;
  - **зелёная ↗** (в остальных лентах) — открыть пост в новой вкладке;
  - **серая →** — следующая запись.
- В фото-папках вместо пустого тела записи показывается само фото, под ним — реальный размер в пикселях. Если в посте несколько фото, показываются все.
- Следующие две записи подгружаются заранее.
- Имя файла — подпись под фото (обычно имя модели) + последние 6 цифр id поста, например `Ave Estel_248576.png`.
- Если пост удалён, запись показывается как обычно в Inoreader.

## Настройки

В начале файла, блок `НАСТРОЙКИ / SETTINGS`:

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `PHOTO_FOLDERS` | `['Photo_every', 'Photo_Tumblr']` | Точные названия фото-папок |
| `PRELOAD` | `2` | Сколько записей подгружать заранее |
| `TITLE_TAP_NEXT` | `true` | Тап по заголовку в фото-папке: открыть пост и перейти дальше |
| `FAB_RIGHT`, `FAB_BOTTOM` | `14`, `115` | Положение кнопок, px |
| `NAME_FROM_CAPTION` | `true` | Имя файла из подписи; `false` — исходное имя |

> Настройки внутри файла перезапишутся при обновлении. Если меняете их — отключите автообновление этого скрипта в Tampermonkey или сохраните свои значения отдельно.

## Ограничения

- Работает в веб-версии Inoreader (в браузере), не в приложении.
- Firefox для Android всегда показывает диалог перед загрузкой файла — скрипт обойти его не может. Папка загрузок задаётся в настройках браузера: *Настройки → Загрузки*.
- Источники кроме Tumblr поддерживаются в общем виде (берутся картинки со страницы поста).

## Если что-то не работает

Откройте запись → меню Tampermonkey → **«Скопировать диагностику»** и приложите содержимое к [issue](https://github.com/Rolarn/Tamper-scripts/issues/new/choose).

### English

Shows the full-size photo from the linked post (Tumblr and generic pages) right inside Inoreader, with floating buttons: *save & next* in photo folders, *open post* elsewhere, and *next entry* everywhere. Settings live at the top of the file. Firefox for Android always asks before saving a file; a userscript cannot skip that dialog.
